# 🎮 Arcade Gallery

**Arcade Gallery** is a retro-inspired web app built with **React** that showcases and lets users play a curated collection of classic and indie games — primarily made with **PICO-8**. Think of it like a modern, nostalgic twist on sites like CoolMathGames.

---

## 🕹 Features

- 🎲 Play embedded PICO-8 games directly in the browser
- 🧩 Smooth and fast user experience built with React
- 📁 Organized game library with categories and thumbnails
- 🔎 Search and explore games by name or genre
- 💾 Lightweight and responsive design

---

## 🚀 Tech Stack

- **Frontend:** React (with Vite)
- **Styling:** Tailwind
- **Game Embeds:** PICO-8 exported HTML cartridges
- **Deployment:** Vercerl(FrontEnd) / SupaBase(Database) / Heroku(BackEnd)
